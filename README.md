# Learn Business Intelligence with Phoebe

A two-track BI course that runs a real mini-BI tool in your browser - pick a dimension and a measure, and watch it write the SQL. No install, no login, no license.

**Live site:** https://phoebefu6.github.io/learn-business-intelligence-with-phoebe/

## Two tracks, one warehouse

- **Leader track (a1-a6)** - for C-level, managers, and anyone who commissions dashboards. Reading and interrogating dashboards, why two dashboards disagree (the semantic layer), commissioning briefs, self-service governance, and a clear-eyed take on tools + AI in BI. No code.
- **Builder track (b1-b10)** - for practitioners. From your first chart to a star schema, governed measures, chart grammar, a shipped executive dashboard, and a full end-to-end investigation of a real revenue dip.

Both tracks live on **Daybreak**, a small coffee-subscription warehouse - the same database as [learn-sql-with-phoebe](https://phoebefu6.github.io/learn-sql-with-phoebe/), all grown up. Every page embeds a live mini-BI playground (`bi-live.js`) powered by SQLite compiled to WebAssembly (sql.js), plus editable SQL editors where the SQL view helps.

## What it teaches from

Mapped session by session in [materials/official-course-map.md](materials/official-course-map.md):

- Microsoft PL-300 exam skills outline (April 2026) + the 5 MS Learn prep paths
- Tableau Desktop Specialist + Certified Data Analyst exam guides
- Google Business Intelligence Professional Certificate framing
- Stephen Few, *Information Dashboard Design* + Cole Nussbaumer Knaflic, *Storytelling with Data*
- The semantic-layer landscape: Power BI semantic models, Looker LookML, dbt MetricFlow

Certificates, videos, and click-path labs stay with the vendors - this course teaches the shared, tool-agnostic core and maps every session to where the official depth lives.
